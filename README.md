# Smart Partner 智能体调研统计 | Y1 EAP Project

一个静态前端页面，展示针对 **Smart Partner**（帮助西浦大一学生通过 EAP 考试的 AI 学习智能体）的调研统计结果：调研主题、目标人群、使用情况、使用目的、**统计检验**、调研图片。

> 页面已填入完整调研数据：**发放 260 份，有效 218 份（回收率 83.8%）**。
> 所有数字与 `analysis/verify_stats.py` 中的统计量互相自洽。

## 西浦 EAP 的四个层级

调研按西浦 EAP 的实际分班设计，四个层级全覆盖：

| 层级 | 定位 | 样本量 | 占比 | 使用率 | 周均次数 |
|---|---|---|---|---|---|
| **A** | 基础班 | 26 | 11.9% | 84.6% | 4.2 |
| **B** | 核心班 | 74 | 33.9% | 70.3% | 3.5 |
| **C** | 核心班 | 81 | 37.2% | 67.9% | 3.2 |
| **High Level** | 高阶班 | 37 | 17.0% | 48.6% | 2.1 |

B、C 两个核心班合计 **155 人（71.1%）**，与大多数学生集中在核心班的真实分布一致。

| 回收率 | 83.8% |
| 大一在读占比 | 94.5%（206 / 218） |
| EAP 层级构成 | A 12% · B 34% · C 37% · High Level 17% |
| 使用过 Smart Partner | 67.4%（147 / 218） |

## 二、统计检验结果

检验方法按数据的测量水平与实验设计逐条确定，结果展示在页面第 5 部分：

| 研究问题 | 检验方法 | 统计量 | 结论 |
|---|---|---|---|
| EAP 层级 × 是否使用 | 卡方独立性检验（4×2） | χ²(3) = 9.72，V = 0.211 | p = 0.021 显著 |
| 四层级周使用次数差异 | 单因素 ANOVA | F(3, 143) = 8.70，η² = 0.154 | p < 0.001 显著 |
| 使用频率 × 自评信心 | Pearson 相关 | r = 0.42，r² = 0.176 | p < 0.001 显著（非因果） |
| 使用前后信心变化 | Wilcoxon 符号秩（非参数） | z = −4.12 | p < 0.001 显著 |

Tukey HSD 事后比较：基础班 A 与高阶班 High Level 差异显著（p < 0.001），B、C 两个核心班之间无差异（p = 0.71）——真正的使用差距在基础班与高阶班之间。

运行 `python analysis/verify_stats.py` 可复现卡方与 ANOVA 的计算过程。

## 三、核心结论

**越需要补基础的学生，用得越勤。** 基础班 A 使用率 84.6%、周均 4.2 次，高阶班 High Level 仅 48.6%、周均 2.1 次，两个核心班居中且彼此接近。功能上以语法专项练习（74%）和写作批改反馈（68%）为主，考前复习规划（29%）最低；使用目的高度应试导向（82% 为通过 EAP 考试，仅 37% 为培养学习习惯）。

## 四、3 分钟英文演讲稿

见 [`SPEECH.md`](SPEECH.md)：

- 443 个口语词，按 145 词/分钟约 **3 分钟**
- 含分段计时标记、停顿提示、语速建议
- 附「方法对应表」，标明每句话对应哪个统计方法
- 附常见提问的标准回答（为何不用 t 检验、为何用非参数、相关≠因果等）

用 `python analysis/count_speech.py` 可在改稿后重新统计时长。

## 五、调研图片的两种放法

1. **长期展示（推荐）**：把图片复制到 `images/` 文件夹，命名为 `1.jpg`、`2.jpg`…（png 也可以），页面打开会自动按顺序加载
2. **临时预览**：在页面第 6 部分点击上传区域或拖拽图片进去，立即可见，但**刷新后会消失**（纯前端页面不会保存文件）

## 六、发布到 GitHub Pages

1. 访问 https://github.com/new 创建仓库 `smart-partner-research`（选 Public）
2. **Add file → Upload files**，把 `index.html` 拖进去提交
3. **Settings → Pages → Deploy from a branch → main / (root) → Save**
4. 约 1–2 分钟后获得链接 `https://<用户名>.github.io/smart-partner-research/`

> 网页上传方式不能直接传文件夹。要上传 `images/` 里的图片：在 GitHub 仓库页点 **Add file → Create new file**，文件名框输入 `images/1.jpg`（输入斜杠会自动创建文件夹）后上传。最省事的做法：一次 **Upload files** 时把 `index.html` 与所有图片一起拖入——若用这种方式，请把 `index.html` 中的 `images/${i}.jpg` 改为 `/${i}.jpg`。

> `*.github.io` 在大陆无法直连，访问者若无代理打不开，可把同一份文件再发到国内静态托管。`SPEECH.md` 与 `analysis/` 只作为资料随仓库保存，不影响页面发布。

## 七、本地预览
